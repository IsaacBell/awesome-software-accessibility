## Accessibility Testing

- [axe-core](https://github.com/dequelabs/axe-core) - The leading open-source accessibility testing engine; runs automated checks in browsers and CI.
- [Pa11y](https://pa11y.org/) - Automated accessibility testing for continuous integration, with a dashboard for trend tracking.
- [WAVE](https://wave.webaim.org/) - Web accessibility evaluation tool that identifies errors and contrast issues directly in the browser.
- [Accessibility Insights](https://accessibilityinsights.io/) - Microsoft's free tooling for finding and fixing accessibility issues.

## Text-to-Speech & Voice Readers

- [KittenTTS](https://github.com/KittenML/KittenTTS) - State-of-the-art text-to-speech model under 25 MB, designed to run on-device.
- [NeuTTS](https://github.com/neuphonic/neutts) - On-device neural text-to-speech model from Neuphonic; model weights on [Hugging Face](https://huggingface.co/neuphonic/neutts-air).
- [Speech Synthesis Markup Language (SSML)](https://www.w3.org/TR/speech-synthesis11/) - The W3C standard for controlling how text is spoken: pauses, pitch, rate, and pronunciation.
- [Piper](https://github.com/rhasspy/piper) - Fast, local neural text-to-speech engine with support for many languages.
- [eSpeak-NG](https://github.com/espeak-ng/espeak-ng) - Compact open-source speech synthesizer that runs on almost any platform.

## Mobile Operating System Accessibility

### Vision Settings

- [Accessibility features for vision on iPhone](https://support.apple.com/en-lamr/guide/iphone/iph732dc028d/ios) - Apple's display settings: text size, bold, contrast, and "reduce motion."
- [Adjust the display and text size on iPod touch](https://support.apple.com/guide/ipod-touch/display-text-size-iph3e2e1fb0/ios) - Screen brightness, zoom, and grayscale/color-filter settings for lower vision.
- [Use Magnifier on iPhone](https://support.apple.com/guide/iphone/iphd335ef2e0/ios) - Turn your iPhone into a magnifying glass for reading small text.
- [Android — Turn on TalkBack](https://support.google.com/accessibility/android/answer/6283677) - Android's built-in screen reader for spoken feedback and gesture navigation.
- [Android — Dark theme and color inversion](https://support.google.com/accessibility/android/answer/6151800) - Reduce eye strain and improve visibility with dark theme and inverted colors.
- [Android — Screen magnification](https://support.google.com/accessibility/android/answer/6006949) - Zoom into the screen with magnification gestures.

### Hearing Settings

- [Live Captions on iPhone](https://support.apple.com/guide/iphone/iphf5e2cfab0/ios) - Real-time captions for calls, videos, and conversations.
- [Android Live Caption](https://support.google.com/accessibility/android/answer/9350862) - Real-time captions for media and calls on Android.
- [Made for iPhone hearing aids](https://support.apple.com/en-us/HT201466) - Pair compatible hearing aids directly with iPhone.
- [Android — Connect hearing aids to your device](https://support.google.com/accessibility/android/answer/9426888) - Pair hearing aids and cochlear implants with Android.

### Motor & Switch Access

- [Apple Voice Control (iPhone/iPad)](https://support.apple.com/en-us/111778) - Voice-based navigation and dictation for iOS and iPadOS.
- [iOS Switch Control](https://support.apple.com/guide/iphone/iph5ac8ba848/ios) - Operate iPhone with switches, adaptive devices, and head movements.
- [Android Switch Access](https://support.google.com/accessibility/android/answer/6122836) - Navigate Android using switches or an external keyboard.

- [Gigaset GL395](https://www.gigaset.com/hq_en/gigaset-gl395/) - Senior-friendly mobile phone with large buttons and an emergency call function.
- [KISA Phone](https://kisa.com.au/kisa-phone) - Simple mobile phone designed for elderly users and people with disabilities.
- [Lively Jitterbug Flip2](https://shop.lively.com/products/jitterbug-flip2-flip-phone) - Simple flip phone with large buttons, loud speakers, and a live 24/7 operator service.

## Responsive Design & Media Queries

- [CSS media queries (MDN)](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries) - The official guide to targeting specific devices, screen sizes, and accessibility preferences via CSS.
- [Responsive web design (MDN)](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) - Learning path for building sites that adapt to any device size.
- [prefers-reduced-motion (MDN)](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion) - CSS media feature for honoring a user's reduced-motion preference.
